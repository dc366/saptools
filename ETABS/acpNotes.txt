## Key Concepts
- Concept 1: what is "attach_ETABS.py" and what is this api doing?

I used copilot to learn about attach_ETABS class.  Here's what I learned:

The attach script is setting up a new class that has as attributes the ETABS program instance and the model.
When you call the attach file class by saying a = attach_ETABS.sapApplication() it is setting up a as a new object of this class 
that is being defined therein.  you can then access the model through the sapModel attribute by doing like a.sapModel...stuff.
The github copilot was useful for learning about the code in this example.
